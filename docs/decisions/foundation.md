| Open point | Choice | Why |
|---|---|---|
| Package path of the canonical rules | `inbox/internal/rules`, not `inbox/internal/validate` as contract section 5 says | The foundation task names `internal/rules`. The inbox stream imports `github.com/PetarMatan/parley/inbox/internal/rules` |
| Names in `tags.stripped` | `zero-width`, `bidi`, `unicode-tag`, `bom`, `html-comment`, `image`, `link`, `tag`, `blank-lines`, always in that order, no duplicates | The contract names only two. A fixed order lets both implementations compare arrays exactly |
| Hidden-character classes | zero-width = U+200B–U+200D, U+2060–U+2064; bidi = U+200E, U+200F, U+202A–U+202E, U+2066–U+2069; unicode-tag = U+E0000–U+E007F; bom = U+FEFF | Splits the contract ranges into the four classes the vectors test |
| Cleaning order | Hidden characters first, then repeat {HTML comment, image, link, tag} until the text stops changing (max 8 passes), then blank lines | Hidden characters can split `<!--` or a secret. One removal can join the halves of another tag (`<<b>system-reminder>`) |
| Unterminated HTML comment | `<!--` without `-->` removes the rest of the text | Otherwise an open comment hides content from a markdown renderer but not from the model |
| Tag shape | `</?name( attrs)?/?>`, name = letter then `[A-Za-z0-9_:.-]*`. `<https://x>` is not tag-shaped and stays | Matches what a model reads as a frame. `a < b` and `a <= b` are never tags |
| Markdown link result | `[t](u)` becomes `t` directly, with no trailing space | Same result as the contract's two-step rule without leaving a stray space |
| Blank-line collapse | A run of more than 2 blank lines (whitespace-only lines count) becomes exactly 2 blank lines | Literal reading of "collapse more than 2 blank lines" |
| Cleaning a `suggested_patch` | Hidden characters, HTML comments and tags apply. Markdown and blank-line rules do not. A tag-shaped match directly after an identifier character (`a<b && c>d`, `Array<string>`) stays, unless it is a closing tag, its name has a hyphen, or its name is a frame name (`channel`, `system`, `system-reminder`, `user`, `assistant`, `human`, `instructions`) | "Keeps `<` and `>` that are not tag-shaped": code generics and comparisons must survive, imitated frames must not. Exported as `rules.FrameNames` |
| Fields cleaned | finding: `title`, `note` (prose), `suggested_patch` (patch). reply: `note`. note.v1: `body` (prose) | note.v1 bodies reach the merge request and the next model that reads it |
| Secret scan input | Both the raw and the cleaned text of every cleaned field | Cleaning joins a secret split by zero-width characters; a secret inside a comment was still sent |
| Injection score formula | 0.25 per distinct keyword, case-insensitive substring match, capped at 1.0. Computed on cleaned text | Simple to mirror exactly in Node. Substring matching over-tags (`pushed`), which is acceptable for a tag that never blocks |
| Length unit | Unicode code points, checked on the raw value before cleaning | Same as JSON Schema `maxLength`. Checking raw stops oversized payloads padded with hidden characters |
| Error codes | `bad_json` (syntax, not an object), `unknown_field`, `invalid_type`, `missing_field` (absent or null), `bad_enum`, `too_long`, `empty_field` (blank required text, or title blank after cleaning), `invalid_field` (schema, context_id, task_id, file path, line, commit), `secret_detected` | Contract fixes only `secret_detected` and the inbox codes |
| `line` ≥ 1 in the shared rules | Checked in `rules` and in the vectors (`invalid_field`) | Contract lists it as inbox-only; it costs nothing to mirror and matches `minimum: 1` in the schema |
| `file` shape | Repository-relative, ≤ 512 code points, no leading `/`, no `\`, no empty, `.` or `..` segment, no control or hidden characters | A path is not cleaned, so anything odd is rejected |
| Required text fields | `title`, `note` (finding and reply) and `body` must be non-blank. `suggested_patch` and `commit` are optional | Contract shows them without "optional" |
| `context_id` pattern | `^[A-Za-z0-9._-]+(/[A-Za-z0-9._-]+)*![1-9][0-9]{0,9}$`, ≤ 256 | `<repo>!<iid>` with an integer iid |
| Blocked-file globs | A pattern without `/` matches the base name at any depth (gitignore rule), so nested `CLAUDE.md` and `Dockerfile.*` are blocked. A pattern with `/` is anchored at the root. `**/` matches zero or more directories. Matching ignores case | Claude Code loads nested `CLAUDE.md`. macOS file systems are case-insensitive, so `claude.md` reaches the same file |
| Vector `input` as a string | A JSON string `input` is the literal request body; any other value is the body as written | Needed for malformed JSON cases. The Node mirror must do the same |
| Vector `stripped` comparison | Exact array equality when present | Forces the same order in both implementations |
| `vectors.json` source | Generated by `schema/gen-vectors.mjs` (`make vectors`) | Long strings (over-length cases) and escaped non-printables are error-prone by hand. The JSON file stays the shared contract |
| Envelope schema | `schema/envelope.v1.json`; `from` and `to` are `direct-identifier` (PII marker convention); `payload` is `oneOf` finding/reply by `$id` | Emails identify a person directly |
| Repository id normalization | Strip scheme, `user@` and host (and port); for scp form `git@host:group/proj.git` take the part after `:`; strip a leading `/` and a trailing `.git`. A local path or `file://` URL becomes `local/<basename without .git>`. Do not resolve symlinks | One id for the same project across HTTPS, SSH and local remotes |
| Getting `local/shop` from `$AIC_WORK/origin.git` | setup.sh creates a symlink `$AIC_WORK/shop.git -> origin.git` and clones from it, so the clones' remote basename is `shop.git` | The contract fixes both the bare repo path and the repo id; the alias reconciles them without a new identity.json field |
| Mint idempotence | setup.sh mints only when `keys/jwks.json` or the promoter token is missing; `AIC_REMINT=1` forces it | Re-minting changes the JWKS under a running gateway |
| Plugin install | `npm ci` when `plugin/package-lock.json` exists, else `npm install`, only if `node_modules` is missing | `npm ci` fails without a lock file |
| git in setup.sh | Runs with `core.hooksPath=/dev/null`, signing off, `init.defaultBranch=main`; author and committer set per commit | The user's global git config must not change the sandbox |
| Absolute paths in the committed `.claude/settings.json` and `.mcp.json` | Hook commands are `node "<ROOT>/plugin/hooks/<name>.mjs"`, MCP args `["<ROOT>/plugin/server.mjs"]`, resolved at setup time | Task requirement; the sandbox origin is machine-local anyway |
| Sandbox bug | `applyPercentDiscount(price, pct)` does not clamp `pct`: 150 gives a negative price, a negative pct raises the price. The 5 tests pass | One real, `fact`-class bug a reviewer finds |
| `make clean` scope | Removes `$AIC_WORK/bin` only; `make reset` runs `sandbox/reset.sh` to delete all of `$AIC_WORK` | Deleting keys, store and repos needs a confirm prompt |
